Sistema Full Stack de gerenciamento de tarefas desenvolvido com foco em uma experiência moderna e organizada.

## 🤖 SmartFeedback AI

Aplicação Full Stack para análise de feedbacks de clientes utilizando **Inteligência Artificial**.

O sistema permite enviar feedbacks e utiliza a API do **Google Gemini** para analisar os comentários, identificar sentimentos, gerar avaliações e produzir insights sobre as opiniões dos clientes.

A aplicação também possui dashboard para acompanhamento das informações e histórico dos feedbacks analisados.

### Tecnologias

`React.js` `JavaScript` `Node.js` `Express.js` `MongoDB` `Axios` `Google Gemini` `API REST`

🔗 [Acessar SmartFeedback AI](https://smartfeedback-ai.vercel.app/)
